# Project Agent

Project Agent is a Python application that searches live remote job listings by job title and preferred location.

## Current features

- Searches live listings from RemoteOK
- Filters jobs by title
- Filters by preferred location
- Supports remote and worldwide searches
- Displays the company, location, and application URL
- Handles searches with no matching results
